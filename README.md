# run-planner

Builds a running plan in `plans/plan_builder.xlsx` and pushes it to the Intervals.icu
calendar, which syncs to Garmin Connect.

## Setup (Windows PowerShell)
    python -m venv .venv
    .venv\Scripts\Activate.ps1
    pip install -r requirements.txt
    copy .env.example .env   # then fill in your API key and athlete ID

## Use
Close the workbook in Excel first (Excel locks open files).

    python layout.py plans/plan_builder.xlsx           # Schedule -> Layout tab
    # review the Layout tab in Excel, edit if needed, close Excel
    python push.py plans/plan_builder.xlsx --dry-run   # check what will be sent/deleted
    python push.py plans/plan_builder.xlsx             # send
    python -m pytest                                   # run tests

## Workbook
- **Config**: `race_date`, `plan_tag`, `long_run` (day), `hard_categories`,
  `source_week_end` (the weekday the Schedule's weeks end on), `taper_days`.
- **Library**: workouts. `workout_text` uses ` / ` for line breaks and Intervals.icu syntax
  (`m` = minutes, `mtr` = meters, every step starts with `- `).
- **Schedule**: the source plan as week / day / workout_id, in its own week convention.
  The highest week number is race week. Blank `workout_id` (or a missing day) = rest.
- **Layout**: generated by layout.py; one row per day with real dates. Blue rows were moved,
  yellow rows break a rule. Re-running layout.py overwrites this tab, so make lasting
  changes in Schedule.

## Rules layout.py enforces
Race on `race_date`; long run on `long_run`; no back-to-back hard days (including across
weeks); no hard day within `taper_days` of the race; key sessions keep their source order
and move as little as possible. Weeks it can't solve are flagged, never dropped.

## Push behaviour
Events are upserted on `<plan_tag>-<date>`. After pushing, events from the same `plan_tag`
on dates that no longer have a workout are deleted. Race rows are not pushed.

## Importing a plan
One-time setup (adds the Paces tab and Config keys; safe to rerun):

    python setup_workbook.py plans/plan_builder.xlsx

Then fill in `threshold_pace` in Config (e.g. `7:30/mi`). For each plan:

    python import_plan.py prompt plans/plan_builder.xlsx
    # paste imports/prompt.md into Claude with the plan; save the CSV it returns
    python import_plan.py stage plans/plan_builder.xlsx imports/<plan>.csv
    # review the Import tab: green = already in Library, yellow = similar (fill 'action')
    python import_plan.py apply plans/plan_builder.xlsx --week-end sun
    # set race_date / plan_tag / long_run in Config, then layout.py and push.py

To add a plan's workouts to Library without touching Schedule, Config or Layout:

    python import_plan.py apply plans/plan_builder.xlsx --library-only

`action` on the Import tab: `add` keeps the workout as a new Library entry (renamed with
`-2` if the ID is taken), or type an existing workout_id to use that one instead.

Pace targets in the CSV are keys like `{T}` or `{T+20s}` from the Paces tab; the importer
turns them into percentages. Offsets are seconds of pace per threshold_pace unit.
Warmups, cooldowns, single continuous runs and untimed recoveries use `Press lap`
(the importer rejects workouts that don't).
